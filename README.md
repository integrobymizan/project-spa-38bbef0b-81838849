# Welcome to your AI Studio project

This project was built with AI Studio.

## Development

Prefer working locally? You need Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Omni AI Builders 3D site

The complete static 3D website (Omni the 3D website helper, chat guide, 11 service
pages) lives in `public/omni/` and is served at `/omni/index.html`.
It is plain HTML, CSS and JavaScript. Its source and editing tools live in the
`integrobymizan/ariyan` repository; edit it there and copy the built files here.
