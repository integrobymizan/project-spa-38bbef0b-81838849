# Welcome to your AI Studio project

This project was built with AI Studio.

## Development

Prefer working locally? You need Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

## Omni AI Builders 3D site

The site's home address shows the Omni AI Builders 3D website: Omni the 3D
website helper, the chat guide and 11 service pages. It is plain HTML, CSS and
JavaScript in `public/` (`index.html`, `assets/`, `services/`), and
`src/routes/index.tsx` serves `public/index.html` at `/`. The old `/omni/`
address forwards to the home page.

Its source and editing tools live in the `integrobymizan/ariyan` repository;
edit it there and copy the files into `public/`.
